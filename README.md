# Portfolio
Shreya Tarade --- Portfolio Website
Welcome to my personal portfolio website! 

This website introduces me and presents my web development work, skills,
experience, and contact details in one place. It features a dark theme
with bright green accents and a responsive layout.

✨ Features
- Home: Introduction and links to connect with me.
- Services: Overview of the web development services showcased on
  the website.
- About: Experience, education, skills, and additional
  information.
- Projects: A dedicated place to showcase my projects.
- Contact: Contact details and a message form layout.
- Responsive layout: Designed to work across desktop, tablet, and
  mobile screens.
- Interactive elements: Navigation, social links, and page
  interactions.
  
🛠️ Built With
- HTML5 --- page structure
- CSS3 --- styling, layout, and responsive design
- JavaScript --- interactive functionality
- Phosphor Icons --- interface icons
